# 编译、链接与头文件

当天目标：知道一个 `.cpp` 如何变成可执行文件，以及为什么 C++ 项目会出现“未定义符号”和“重复定义”。

- 区分声明与定义；函数声明可以放头文件，定义通常只能有一份。
- 理解编译单元：每个 `.cpp` 连同它 `#include` 的内容独立编译。
- 理解链接器把多个目标文件拼接起来；看到 undefined reference 时先检查实现是否参与编译。
- 使用 `#pragma once` 或 include guard 防止头文件重复包含。

练习：拆分一个 `Calculator` 为 `.h` 和 `.cpp`，故意漏掉 `.cpp` 再观察链接错误。
