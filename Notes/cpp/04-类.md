# 类：把状态和规则放在一起

类不仅是“带函数的结构体”。它最重要的用途，是保证对象从构造完成到析构之前始终处于可用状态，并把不允许的操作挡在接口外面。

## 1. class 与 struct 的核心差别只是默认访问权限

```cpp
struct Point {      // 成员默认 public
    int x = 0;
    int y = 0;
};

class Counter {    // 成员默认 private
    int value_ = 0;
};
```

二者都能有构造函数、成员函数、继承和模板。工程上常用 `struct` 表示简单数据，用 `class` 表示需要维护规则的对象，这是一种约定，不是语言强制。

## 2. 构造函数建立不变量

**不变量（invariant）**是对象处于正常可用状态时必须一直满足的条件。例如账户余额不能为负，就应在构造和修改入口统一检查，而不是让每个调用者自己记住规则。

```cpp
class Account {
public:
    explicit Account(int balance) : balance_(balance) {
        if (balance < 0) throw std::invalid_argument("negative balance");
    }

private:
    int balance_;
};
```

单参数构造函数常加 `explicit`，避免 `Account account = 100;` 这种不明显的隐式转换。

## 3. const 成员函数承诺不修改当前对象

```cpp
int balance() const { return balance_; }
```

末尾的 `const` 限制成员函数中的 `this` 视图，因此 `const Account` 也能调用它。它不保证全局状态不变，也不自动解决多线程同步。

## 4. 组合通常比继承更直接

```cpp
class Engine {};

class Car {
    Engine engine_; // Car 拥有一个 Engine：组合
};
```

组合表达“有一个”，继承表达“是一个并可替换”。若只是复用几行实现，优先组合；真正需要通过基类接口操作不同实现时，再使用多态继承。

## 5. 完整示例：一个维护不变量的类

```cpp title="class_demo.cpp"
#include <iostream>
#include <stdexcept>
#include <string>
#include <utility>

class BankAccount {
public:
    explicit BankAccount(std::string owner) : owner_(std::move(owner)) {}

    void deposit(int amount) {
        if (amount <= 0) throw std::invalid_argument("deposit must be positive");
        balance_ += amount;
    }

    bool withdraw(int amount) {
        if (amount <= 0 || amount > balance_) return false;
        balance_ -= amount;
        return true;
    }

    const std::string& owner() const { return owner_; }
    int balance() const { return balance_; }

private:
    std::string owner_;
    int balance_ = 0;
};

int main() {
    BankAccount account("Ada");
    account.deposit(100);
    std::cout << account.owner() << ' ' << account.balance() << '\n';
    std::cout << std::boolalpha << account.withdraw(120) << '\n';
}
```

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic class_demo.cpp -o class_demo
./class_demo
```

输出为 `Ada 100` 和 `false`。调用者无法直接把 `balance_` 改成负数，规则集中在类内部。

## 6. 头文件与实现文件怎么分

公开声明放 `.h`，较长的函数体放 `.cpp`。这样调用方只依赖接口；私有实现变化不会把所有细节暴露出去。简单访问器可以留在类体内，但公共头文件中的定义仍要遵守 ODR。类的布局、虚函数和生命周期继续分别见第 05、07、15 篇。

规则细节可查 C++17 工作草案 N4659 的 Clause 12 `[class]`。
