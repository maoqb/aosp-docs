# 类模版

> 类模板是“用模板生成不同类型的类”。

```
template <typename T>
class Box {
public:
    void set(T value) {
        mValue = value;
    }

    T get() {
        return mValue;
    }

private:
    T mValue;
};
```

这里：`template <typename T>`表示：接下来定义的是一个类模板，其中 `T` 是类型参数。

使用的时候指定具体类型：

```
Box<int> box1;
Box<double> box2;
Box<std::string> box3;
```

分别可以理解成：

```
Box<int>
   ↓
T = int
```

编译器得到的类概念上类似：

```
class Box<int> {
public:
    void set(int value);
    int get();

private:
    int mValue;
};
```

这和 Java 泛型看起来语法上很像，但底层思想不是一回事：

```
Java 泛型：主要采用类型擦除等机制

C++ Template：编译器针对具体模板参数进行实例化
```

另外，类模版的T可以出现到以下这些位置：

```
template <typename T>
class Box {
public:

    Box(T value)
        : mValue(value) {
    }

    void set(T value) {
        mValue = value;
    }

    T get() const {
        return mValue;
    }

    T* getPointer() {
        return &mValue;
    }

    T& getReference() {
        return mValue;
    }

private:
    T mValue;
};
```
