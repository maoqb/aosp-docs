# 标准算法：把“遍历做什么”写清楚

`<algorithm>` 中的函数把遍历模式封装起来。它们通常接收一对迭代器表示半开区间 `[first, last)`，调用者提供比较器或 Lambda 描述业务条件。

## 1. 先认识半开区间

`begin()` 指向第一个元素，`end()` 指向最后一个元素之后的位置。空区间满足 `begin() == end()`，两个位置相减或逐步前进可得到元素数量。这种约定能自然表示空容器和子区间。

```cpp
auto it = std::find(values.begin(), values.end(), 42);
if (it != values.end()) {
    std::cout << "found";
}
```

## 2. 常用算法分别解决什么

```cpp
std::sort(v.begin(), v.end());
bool any = std::any_of(v.begin(), v.end(), pred);
std::transform(v.begin(), v.end(), out.begin(), func);
int sum = std::accumulate(v.begin(), v.end(), 0);
```

- `sort` 改变元素顺序，要求随机访问迭代器，因此适合 `vector`，不直接用于 `list`。
- `find`/`find_if` 返回位置；找不到时返回结束迭代器。
- `transform` 把每个输入映射为输出，目标区间必须有足够空间，或使用插入迭代器。
- `accumulate` 位于 `<numeric>`，初始值类型会影响累加类型；大整数求和应写 `0LL` 而不是 `0`。

## 3. remove 没有真的缩短 vector

```cpp
auto newEnd = std::remove_if(v.begin(), v.end(), pred);
v.erase(newEnd, v.end());
```

`remove_if` 把保留元素移到前面并返回新的逻辑末尾，真正改变容器大小的是 `erase`。这就是 C++17 常见的 erase-remove 写法。

## 4. 完整示例：过滤、排序、去重和求和

```cpp title="algorithm_demo.cpp"
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> values{5, -1, 3, 5, 2, -7, 3};

    values.erase(std::remove_if(values.begin(), values.end(),
                                [](int value) { return value < 0; }),
                 values.end());
    std::sort(values.begin(), values.end());
    values.erase(std::unique(values.begin(), values.end()), values.end());

    const int sum = std::accumulate(values.begin(), values.end(), 0);
    for (int value : values) std::cout << value << ' ';
    std::cout << "sum=" << sum << '\n';
}
```

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic algorithm_demo.cpp -o algorithm_demo
./algorithm_demo
```

输出 `2 3 5 sum=10`。`unique` 只消除相邻重复项，所以先排序；若不能改变原顺序，需要选择其他数据结构或单独记录已见元素。

## 5. 比较器必须前后一致

`sort`、`map` 的比较器需要形成稳定的严格弱序。不要让比较结果依赖不断变化的全局状态，也不要写 `a <= b`；常用升序判断是 `a < b`。算法运行期间修改参与比较的键，会破坏它对顺序的假设。

规则细节可查 C++17 工作草案 N4659 的 Clause 28 `[algorithms]` 与 §29.8 `[numeric.ops]`。
