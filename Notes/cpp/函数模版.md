# 函数模版

> 函数模板 = 给编译器一份“生成函数的模板”，让同一套函数逻辑可以用于不同类型。
>
> 模板可以理解为“编译期生成代码的规则”。

```
template <typename T>
T maxValue(T a, T b) {
    return a > b ? a : b;
}
```

template &lt;typename T&gt; 里的 `T` 可以理解成暂时是一个“类型占位符”，编译器可以根据参数推导T的实际类型。例如：

```
maxValue(1.5, 2.8);
```

推导：

```
T = double
```

相当于生成：

```
double maxValue(double a, double b) {
    return a > b ? a : b;
}
```

这叫：**模板实例化（template instantiation）**
