# C++ 知识点目录

按文件顺序学习各主题，并带着问题去读对应的 Android 源码；不需要等全部学完才开始读 Binder 或 JNI。

| 顺序 | 文件 | 核心知识点 |
| --- | --- | --- |
| 01 | `01-编译链接与头文件.md` | 编译单元、声明/定义、链接、头文件保护 |
| 02 | `02-对象生命周期与初始化.md` | 栈/堆、初始化、构造与析构 |
| 03 | `03-指针引用与const.md` | `T*`、`T&`、`const`、空值与借用 |
| 04 | `04-RAII与资源管理.md` | 确定性析构、文件描述符、锁 |
| 05 | `05-拷贝移动与值语义.md` | Rule of Zero、拷贝、移动、`std::move` |
| 06 | `06-智能指针与所有权.md` | `unique_ptr`、`shared_ptr`、`weak_ptr` |
| 07 | `07-字符串容器与范围for.md` | `string`、`vector`、迭代器、`auto` |
| 08 | `08-类继承虚函数与接口.md` | 虚函数、纯虚接口、`override`、`final` |
| 09 | `09-模板Lambda与回调.md` | 模板阅读、Lambda 捕获、`std::function` |
| 10 | `10-错误处理与调试工具.md` | 返回状态、断言、Sanitizer、日志 |
| 11 | `11-线程锁与原子变量.md` | `mutex`、RAII 加锁、条件变量、原子变量 |
| 12 | `12-JNI边界.md` | `JNIEnv*`、引用类型、线程 attach、异常 |
| 13 | `13-Android-RefBase-sp-wp.md` | `RefBase`、`sp<>`、`wp<>`、生命周期 |
| 14 | `14-Binder与Parcel.md` | `IBinder`、Proxy/Stub、`Parcel`、事务 |
| 15 | `15-AIDL-NDK与系统服务.md` | AIDL 生成代码、服务注册、Native 调用链 |
| 16 | `16-BufferQueue与SurfaceFlinger入口.md` | BufferQueue、生产者/消费者、图形栈入口 |

每篇文档均包含概念、原理、Android 源码阅读切入点和常见误区。读源码时始终记录三个问题：谁拥有对象、在哪个线程运行、失败怎么返回。
