## 阅读约定

这套文档面向有 Java 基础、需要阅读 Android Native 源码的开发者。正文围绕知识本身展开，结合语言规则、完整示例、运行结果、错误分析和源码入口，不以每日目标或任务清单代替讲解。

- 通用语言示例以 **C++17** 为基线；涉及 C++20 / C++23 的功能会单独标明，不要求先升级工具链。
- Android 专题以 **AOSP `android-16.0.0_r4`** 为源码基准；阅读其他分支时，先核对路径、接口与生命周期约定。
- 带文件名的代码块用于组织完整示例；仅展示某个接口或错误写法的片段，会在正文说明上下文，不能直接当作独立程序运行。
- Linux 主机示例、JNI 主机 JVM 示例与 AOSP 平台示例的依赖不同。平台代码需要对应头文件、生成代码、运行库及设备集成，不能只用桌面 `g++` 代替整个 Android 构建环境。
- 标明未定义行为的代码用于解释故障，尤其是 Sanitizer 诊断示例，不属于可以复制到业务代码中的正确实现。

从第 01 篇顺序阅读有助于建立语言基础；遇到 Android 源码里的具体问题，也可以按目录回查。始终追问：**谁拥有对象、存活到什么时候、在哪个线程运行、谁保证同步、失败怎么返回。**
